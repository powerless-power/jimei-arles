# 2026 集美·阿尔勒导览

整理第十二届集美·阿尔勒影像艺术季（2026.11.20 — 2027.01.03）的展览分布与开幕周日程。

## 文件结构

| 文件         | 用途                                         |
| ------------ | -------------------------------------------- |
| `index.html` | 入口页，通过 meta refresh 跳转到 `2026.html` |
| `2026.html`  | 完整导览页，包含样式、内容与交互脚本         |

## 个人笔记

每个展览卡片和开幕周活动条目右下角都有「写笔记」入口，可以写文字、附加最多 9 张照片。文字在停止输入 500 毫秒后自动保存，照片会先在浏览器内压缩（最长边 1280px、JPEG 质量 0.8）再保存。

所有内容只保存在当前浏览器的 IndexedDB 中，不上传服务器。同一浏览器再次打开页面时会自动读回；清除浏览器站点数据会一并删除笔记。隐私模式下若 IndexedDB 不可用，页面仍可正常浏览，但笔记入口会禁用。

点击顶部标签栏右侧的「导出笔记 PDF」，可把全部笔记按导览顺序汇总导出为 `集美阿尔勒2026-我的笔记.pdf`。导出组件通过 jsDelivr CDN 按需加载，因此导出时需要联网；其余功能均可离线使用。
