# 2026 集美·阿尔勒导览

整理第十二届集美·阿尔勒影像艺术季（2026.11.20 — 2027.01.03）的展览分布、群岛计划城市漫游、城市平行展与开幕周日程。

## 文件结构

| 文件                      | 用途                                                   |
| ------------------------- | ------------------------------------------------------ |
| `index.html`              | 入口页，通过 meta refresh 跳转到 `2026/index.html`     |
| `2026/index.html`         | 完整导览页，四大 venue 标签与开幕周内容均写在此文件     |
| `2026/app.js`             | 标签切换、笔记、PDF 导出与日历订阅链接生成             |
| `2026/style.css`          | 页面样式                                               |
| `2026/opening-week.ics`   | 开幕周日历订阅源，包含已公布活动                       |

## 开幕周日历订阅

`2026/opening-week.ics` 是静态 iCal 订阅源，包含 11 月 20–22 日已公布的 20 场活动；时间未公布的派对不写入日历。开幕周页面会根据当前访问地址生成 `webcal://` 订阅链接、下载链接和可复制的订阅地址；本地通过 `file://` 打开时只保留下载入口。

用户订阅后，日历应用会定期重新拉取同一个地址。更新 `2026/opening-week.ics` 后，已有订阅会在客户端下次刷新时同步，但不是实时推送。日程变更时需要同时修改 `2026/index.html` 与 `2026/opening-week.ics`，并保留每个事件的 `UID`（UUID）不变，避免订阅端重复创建事件。

## 个人笔记

每个展览卡片和开幕周活动条目右下角都有「写笔记」入口，可以写文字、附加最多 9 张照片。文字在停止输入 500 毫秒后自动保存，照片会先在浏览器内压缩（最长边 1280px、JPEG 质量 0.8）再保存。

每个可写笔记的条目在 HTML 上都有唯一且不变的 `data-note-id`，笔记以该 ID 作为 IndexedDB 主键；今后修改标题、策展人或描述不会再让原有笔记失联。缺失或重复 ID 会在浏览器控制台报错，不再按标题生成 key。本次不迁移历史数据：旧版本已保存的笔记若仍在浏览器中，会按现有逻辑出现在「笔记」页的「其他」分组。

所有内容只保存在当前浏览器的 IndexedDB 中，不上传服务器。同一浏览器再次打开页面时会自动读回；清除浏览器站点数据会一并删除笔记。隐私模式下若 IndexedDB 不可用，页面仍可正常浏览，但笔记入口会禁用。

「笔记」标签按导览顺序预览已记录的笔记，点开卡片可以继续编辑。同一标签页内的「导出笔记 PDF」可把全部笔记汇总导出为 `集美阿尔勒2026-我的笔记.pdf`。导出组件通过 jsDelivr CDN 按需加载，因此导出时需要联网；其余功能均可离线使用。

- 展期、票价、开放时间：三影堂官网参观页。
- 展览与入围名单：三影堂 2026 展览总页、各展专页及官方公众号 / 微博展讯。
- 楼层动线：小宇宙播客「怀炉写真机」前瞻导览与官方展讯交叉比对。
- 开幕周逐场时段、地点、嘉宾与语言：三影堂公众号《【开幕倒计时 3 天】11.20–11.22 开幕周活动全攻略》（2026.11.17，[原文](https://mp.weixin.qq.com/s/zCLTfa3FOokAN1tTmWOh3g)）。导览按文中合并表格拆入各日，派对仍未公布。
- 群岛计划的特别策划、漫游展、艺生活与城市站：三影堂公众号《【开幕倒计时 2 天】群岛计划城市漫游全攻略已生成》（2026.11.18，[原文](https://mp.weixin.qq.com/s/XIGpTMTdc6FJH-eXImxyJg)）。城市站名单与 GR Walk 具体日期原文以图片矩阵呈现，本页不代为列出。
- 城市平行展：三影堂公众号《【开幕倒计时 2 天】2026 集美·阿尔勒平行展：多元艺术生态激活城市活力》（2026.11.18，[原文](https://mp.weixin.qq.com/s/YPSyc_DLh2luYXNSJVJI9A)）。两场平行展使用各自展期；11 月 23 日的开幕不计入开幕周日历。

官方日程变动时，以三影堂发布为准。
